This definition of reflection is Java-centric. All reflection that exists in Java is run-time reflection. It doesn't have to be this way in other languages. When we say "reflection" in C++ context, we usually mean compile-time reflection, something entirely different from that Java-based definition. C++ doesn't have compile-time reflection, it is only vaguely planned for some indefinite future version. It will be "something like define or template" indeed when it exists, bit there is nothing like that now. –
